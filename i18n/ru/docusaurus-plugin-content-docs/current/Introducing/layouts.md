# Телефон, планшет и компьютер

В MOCPilot три варианта интерфейса. Приложение выбирает нужный автоматически:

- **Телефон**: iPhone и телефоны Android.
- **Планшет**: iPad и планшеты Android (от 7 дюймов).
- **Компьютер**: Mac и Windows, а также [веб-редактор](/docs/Introducing/WebEditor) в браузере.

Профили, редакторы и панель управления везде одинаковые; отличается только навигация.

## Телефон

<Screenshot name="profiles-phone" alt="Страница профилей на телефоне с нижней панелью" width={360} />

- В **нижней панели** три раздела: **Профили**, **Настройки**, **Помощь**.
- **Аккаунт** находится вверху **Настроек**.
- В шапке страницы профилей есть **+** (Новый профиль, Импорт профиля…, Искать онлайн), **колокольчик** (Уведомления), кнопка **QR** (подключить пульт) и поле поиска.
- Основные экраны открываются в портретной ориентации. Когда вы открываете профиль, приложение переходит в **альбомную ориентацию на весь экран**, чтобы редактору и панели управления досталось всё пространство. После закрытия профиля возвращается портретная ориентация.
- В редакторе круглые плавающие кнопки дают быстрый доступ к главному экрану, отмене и повтору, ИИ-конструктору, Настройкам редактора, Геймпаду, Моим хабам, Панели, Монитору и кнопке запуска/остановки.

## Планшет

<Screenshot name="profiles-tablet" alt="Страница профилей на планшете с боковой панелью" width={900} />

- В **боковой панели** слева — **Профили**, **Настройки**, **Помощь** и **Аккаунт**. Её можно свернуть до значков кнопкой боковой панели в шапке.
- В шапке профилей есть переключатель вида (**Сетка** / **Столбец**), **Новый профиль**, **Импорт профиля…**, **Искать онлайн**, **Сортировка и фильтр**, **Фильтр по хэштегам** и колокольчик Уведомлений.
- На широких экранах Настройки и Помощь открываются рядом со списком.
- Профиль открывается в альбомной ориентации; в редакторе те же плавающие кнопки, что и на телефоне.

## Компьютер (Mac и Windows)

<Screenshot name="profiles-desktop" alt="«Мои профили» на компьютере" width={900} />

- В **верхней панели** есть меню: **Файл** (Новый профиль, Импорт профиля…, Искать онлайн, Выйти), **Вид** (полноэкранный режим), **Окно** и **Помощь** (Справка MOCPilot, Задать вопрос, Сообщить об ошибке, О MOCPilot). На Mac те же меню находятся в системной строке меню.
- Справа: кнопка **Аккаунт**, **Настройки** (⌘, / Ctrl+,), **Уведомления** и кнопка **QR** для удалённого управления.
- Настройки, Помощь, Аккаунт, Новый профиль, Редактирование профиля, Каталог профилей и другие страницы открываются **окнами** поверх списка профилей.
- Щёлкните карточку профиля, чтобы увидеть действия (Запустить, Изменить…, В избранное, Поделиться…); двойной щелчок запускает профиль.
- В редакторе **Панель** открывается в **отдельном окне**, так что программу и панель управления можно видеть рядом.

### Сочетания клавиш

| Действие | Mac | Windows |
|---|---|---|
| Новый профиль | ⌘N | Ctrl+N |
| Импорт профиля | ⌘O | Ctrl+O |
| Закрыть профиль | ⌘W | Ctrl+W |
| Запустить / Остановить | ⌘R / ⌘. | Ctrl+R / Ctrl+. |
| Отменить / Повторить | ⌘Z / ⇧⌘Z | Ctrl+Z / Ctrl+Shift+Z |
| Показать панель управления | ⌘2 | Ctrl+2 |
| Палитра блоков | ⌘P | Ctrl+P |
| Увеличить / уменьшить / реальный размер | ⌘+ / ⌘− / ⌘0 | Ctrl++ / Ctrl+− / Ctrl+0 |
| Мои хабы | ⇧⌘H | Ctrl+Shift+H |
| Монитор (Логические блоки) | ⇧⌘M | Ctrl+Shift+M |
| ИИ-конструктор | ⇧⌘I | Ctrl+Shift+I |
| Настройки | ⌘, | Ctrl+, |
| Полноэкранный режим | ⌃⌘F | F11 |

## Редактор профиля в любом интерфейсе

В редакторе нет вкладок. **Программа** (строки Быстрых связей или Логические блоки) занимает весь экран, а остальные части открываются кнопками:

| Кнопка | Что открывает |
|---|---|
| **Мои хабы** | [слоты хабов](/docs/Application/Hubs/ConnectingHubs) профиля |
| **Панель** | [панель управления](/docs/Application/Dashboard/DashboardOverview) |
| **Геймпад** | [настройки геймпада](/docs/Application/Dashboard/Gamepad) |
| **Монитор** | значения переменных и списков (только Логические блоки) |
| **Настройки редактора** | [параметры редактора](/docs/Application/BlockBuilder/Editor#editor-settings) |
| **ИИ-конструктор** | [ИИ-конструктор](/docs/Application/BlockBuilder/Editor#ai-builder) (MocPilot Pro) |
| **Проблемы** | строки, которые не могут работать (только Быстрые связи) |
| **Запустить / Остановить** | запуск и остановка программы |
