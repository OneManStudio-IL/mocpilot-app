# Входы

С входа начинается каждая строка. На вкладке **Входы** палитры есть:

- по блоку на каждый **элемент панели** (у джойстиков и крестовин — по блоку на каждую ось);
- один блок **Геймпад**;
- по блоку **Хаб** на каждый хаб профиля (кроме Mould King: у него нет датчиков и кнопок).

Если вкладка пуста: «Добавьте контроллеры на панель или хабы в «Мои хабы»: они появятся здесь».

## Контроллер

Элемент вашей панели управления, указанный по имени: **JOY1**, **SLDR1**, **BTN2**…

| Элемент | Канал | Сигнал |
|---|---|---|
| Джойстик | **Ось X** или **Ось Y** | значение −1…1 |
| Слайдер | — | значение |
| Руль | — | значение −1…1 |
| Педали | — | значение (газ, тормоз) |
| Крестовина | **Вверх / вниз** или **Влево / вправо** | −1, 0 или +1 |
| Кнопка | — | вкл, пока нажата |
| Переключатель | — | вкл / выкл |
| Шаговый переключатель | — | текущая ступень |

Настройки: **Контроллер** (какой элемент) и **Канал** (ось или направление).

Когда вы добавляете, переименовываете или меняете элемент на панели, палитра и строки обновляются автоматически. Если переключить джойстик на «Только по горизонтали (X)», строки с его осью Y сообщат: «… не двигается по этой оси».

## Геймпад {#gamepad}

Один блок на весь геймпад; выберите **Вход**:

- **Стики**: Левый стик Y, Левый стик X, Правый стик Y, Правый стик X (значение −1…1);
- **Триггеры**: RT, LT (PlayStation: R2, L2) (значение);
- **Основные кнопки**: A, B, X, Y (PlayStation: Крестик, Круг, Квадрат, Треугольник) (вкл/выкл);
- **Бамперы**: LB, RB (PlayStation: L1, R1) (вкл/выкл);
- **Крестовина**: Вверх, Вниз, Влево, Вправо (вкл/выкл).

Подписи зависят от параметра **Расположение кнопок геймпада** на [странице «Геймпад»](/docs/Application/Dashboard/Gamepad). Сначала включите там **Включить блоки геймпада**.

## Хаб

Хаб тоже может быть входом — его кнопки и датчики. Настройки: **Хаб**, **Кнопка или датчик**, **Порт** (для устройств на портах) и **Ориентация хаба** (для наклона и ускорения: как хаб установлен в модели). В списке только то, что умеет этот хаб.

| Кнопка или датчик | Единица | Примечания |
|---|---|---|
| **Кнопка 1, 2…** | вкл/выкл | кнопка хаба; кнопки пульта LEGO® Powered Up |
| **Батарея** | % | |
| **Напряжение батареи** | В | |
| **Выходное напряжение** | В | BuWizz 2.0 |
| **Температура** | °C | |
| **Наклон: тангаж / крен / рыскание** | ° | встроенный датчик наклона |
| **Ускорение X / Y / Z** | м/с² | |
| **Скорость мотора** | % | порт |
| **Угол мотора** | ° | относительный, порт |
| **Позиция мотора** | ° | абсолютная (угловые моторы), порт |
| **Мощность мотора** | % | порт, Robot Inventor |
| **Ток мотора** | А | порт |
| **Датчик расстояния** | | порт |
| **Датчик цвета** | | порт |
| **Отражённый свет / Окружающий свет** | % | порт |
| **Датчик наклона: тангаж / крен** | ° | датчик наклона WeDo 2.0 / BOOST на порту |
| **Режим мощности** | 1–4 | BuWizz 2.0 |
| **Подключён** | вкл/выкл | подключён ли хаб |

По строке значение идёт в масштабе −1…1. **Монитор**, поставленный сразу после датчика, показывает реальное значение с единицей измерения, например «7,85 В» или «−12°».

Типичные применения:

- *Батарея* → *Индикатор* (Уровень заряда батареи);
- *Датчик расстояния* → *Порог* (Ниже 20 %) → *Мотор на время*: отъехать, когда что-то близко;
- *Кнопка 1* (пульт Powered Up) → *Мотор*: управление настоящим пультом.
