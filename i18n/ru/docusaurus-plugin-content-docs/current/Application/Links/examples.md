# Примеры

Готовые рецепты. Сначала добавьте элементы на панель управления и хабы в «Мои хабы», потом соберите строки.

## Машина с серворулём

Панель: **JOY1** (Только по вертикали (Y)) слева, **JOY2** (Только по горизонтали (X)) справа, **BTN1**, монитор **Уровень заряда батареи**.

| # | Вход | Обработка | Операция | Выход |
|---|---|---|---|---|
| 1 | JOY1, Ось Y | Мёртвая зона 10 %, Плавность 0,5 с | Мотор | Technic Hub, порты A + B |
| 2 | JOY2, Ось X | | Серво (Авто, ±90°) | Technic Hub, порт D |
| 3 | BTN1 | Защёлка | Свет (мигание: выкл) | Technic Hub, порт C |
| 4 | Хаб: Батарея | | | Индикатор: Уровень заряда батареи |

Если один ходовой мотор крутится не в ту сторону, разделите строку 1 на две и добавьте **Инверсию** в одну из них.

## Танк (две гусеницы)

Панель: два вертикальных слайдера **VSLDR1** и **VSLDR2** с включёнными **Возврат к нулю** и **Отрицательные значения**.

| # | Вход | Обработка | Операция | Выход |
|---|---|---|---|---|
| 1 | VSLDR1 | Плавность 0,25 с | Мотор | Хаб, порт A |
| 2 | VSLDR2 | Инверсия, Плавность 0,25 с | Мотор | Хаб, порт B |

С геймпадом: Левый стик Y для строки 1 и Правый стик Y для строки 2.

## Кран

Панель: **DPAD1**, **SLDR1**, **SWCH1**.

| # | Вход | Обработка | Операция | Выход |
|---|---|---|---|---|
| 1 | DPAD1, Влево / вправо | Ограничение 50 % | Мотор | Хаб, порт A (поворот) |
| 2 | DPAD1, Вверх / вниз | | Мотор | Хаб, порт B (лебёдка крюка) |
| 3 | SLDR1 | Мёртвая зона 10 % | Мотор | Хаб, порт C (стрела) |
| 4 | SWCH1 | | Свет (мигание 0,5 с) | Хаб, порт D (маячок) |

## Поезд

Панель: **Шаговый переключатель** **STPR1** с **Отрицательными значениями** (ступени скорости вперёд и назад), **BTN1** для света.

| # | Вход | Обработка | Операция | Выход |
|---|---|---|---|---|
| 1 | STPR1 | Плавность 2 с | Мотор | City Hub, порт A |
| 2 | BTN1 | Защёлка | Свет | City Hub, порт B |
| 3 | Хаб: Батарея | | | Индикатор: Монитор |

Блок Плавность заставляет поезд трогаться и останавливаться, как настоящий.
