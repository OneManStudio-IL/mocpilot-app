# Запуск и исправление проблем

## Всё ли готово?

Кнопка **Проблемы** в верхней панели редактора показывает:

- **зелёную галочку**: «Все строки готовы»;
- **красный «!»**: «Проблемы: N».

Нажмите её, чтобы открыть панель проблем (боковая панель на телефоне, меню на планшете или компьютере). В ней перечислены пункты «Строка N — причина»; нажмите на пункт, чтобы перейти к этой строке. Блок, из-за которого возникла проблема, обведён **красной рамкой**. Когда всё в порядке: «Каждая включённая строка может работать.»

Строки с проблемами не работают, остальные — работают.

## Частые сообщения

| Сообщение | Что делать |
|---|---|
| Перетащите в строку вход и выход (хаб или индикатор панели) | строка пуста или у неё только один конец |
| Добавьте вход в начало строки | сначала перетащите вход: элемент панели, геймпад или хаб |
| Добавьте операцию перед хабом: мотор, серво, свет | перед выходом Хаб нужна операция |
| Выберите хотя бы один порт хаба | нажмите на порт в блоке Хаб |
| Выберите контроллер панели | нажмите на блок входа и выберите элемент |
| … не двигается по этой оси | джойстик настроен на одну ось; выберите другую ось или измените джойстик |
| «…» не работает с этим контроллером | обработка или операция не подходит к этому входу |
| Порт A: у мотора нет энкодера | используйте мотор с энкодером или другую операцию |
| На порту A датчик, а не мотор | проверьте, что подключено к порту |
| Порт A также используется в строке 2 | каждый порт может использовать только одна строка |
| Включите блоки геймпада на странице «Геймпад» (верхняя панель) | откройте **Геймпад** и включите **Включить блоки геймпада** |
| Индикатор показывает значение как есть: удалите операцию | в строке с Индикатором не бывает операции |
| Выберите хаб с цветным светодиодом (хабы LEGO) | Светодиод хаба работает только на хабах LEGO® |
| Цвета портов есть только у BuWizz 3 | для Цвета порта нужен BuWizz 3.0 Pro |
| В этой программе нет серво в режиме автокалибровки | для Калибровки серво нужно Серво в режиме Авто |
| Для этого блока нужна более новая версия приложения | профиль создан в более новой версии; обновите MOCPilot |
| Строка выключена | включите её в меню строки |

## Текущие значения

Пока программа работает, на каждом стыке между блоками видно проходящее через него значение. Подвигайте элемент управления и проследите значение вдоль строки:

- на входе ничего не меняется — элемент или геймпад не передаёт сигнал; проверьте канал или ось;
- значение меняется, а мотор стоит — проверьте точку подключения хаба и порт;
- после **Ограничения** или **Мёртвой зоны** значение слишком маленькое — поправьте их настройки.

## Модель не двигается

1. Подключён ли хаб? Посмотрите в **Мои хабы** и на точку подключения в блоке Хаб.
2. Выбран ли нужный порт? Моторы подключены туда, куда вы думаете?
3. Строка включена и без красной рамки?
4. Программа запущена (Play)?
5. Заряжена ли батарея? Добавьте строку *Батарея → Индикатор*, чтобы её видеть.

Подробнее — в разделе [Решение проблем](/docs/Help/Troubleshooting).
