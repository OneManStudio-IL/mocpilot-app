# Обработка

Блоки обработки стоят между входом и операцией и меняют значение по пути. В строке их может не быть совсем, может быть один или несколько — в любом порядке. У каждого один вход и один выход.

| Блок | Что делает | Настройки | Работает с |
|---|---|---|---|
| **Инверсия** | меняет направление | — | значениями и вкл/выкл |
| **Ограничение** | ограничивает значение | **Максимум**: 20…90 % (по умолчанию 50 %) | значениями; кнопка становится значением |
| **Мёртвая зона** | игнорирует малые отклонения около нуля | **Зона**: 5, 10, 15, 20, 30 % (по умолчанию 10 %) | значениями |
| **Порог** | превращает значение во вкл/выкл | **Включено, когда значение**: Выше / Ниже; **Уровень (от полной шкалы)**: −50…90 % (по умолчанию 20 %) | значениями |
| **Плавность** | плавно разгоняет и замедляет | **Разгон (до полной скорости)** и **Торможение (до остановки)**: Мгновенно, 0,25, 0,5, 1, 2, 3 с (по умолчанию 0,5 с) | значениями, в том числе для света |
| **Защёлка** | нажал — вкл, нажал ещё раз — выкл | — | вкл/выкл |

## Инверсия

Мотор крутится не в ту сторону? Добавьте **Инверсию**, а не переворачивайте мотор. Для двух моторов, которые должны вращаться в разные стороны (левая и правая гусеница, две стороны коробки передач), сделайте две строки и поставьте Инверсию в одну из них.

## Ограничение

Делает модель медленнее и послушнее: при **Максимуме** 50 % джойстик, отклонённый до упора, даёт половину скорости. Отлично подходит для детей, езды дома и хрупких механизмов.

## Мёртвая зона

Джойстик редко стоит точно в нуле, поэтому мотор может гудеть или медленно ползти. **Мёртвая зона** считает малые значения нулём. Для начала хватит 10 %.

## Порог

Превращает значение во вкл/выкл: «включено, когда значение **Выше** 20 %». С датчиком: *Датчик расстояния* → *Порог* (Ниже, 20 %) включается, когда что-то близко. У порога есть гистерезис, поэтому на границе он не мерцает.

## Плавность

Трогается и останавливается плавно, как настоящая техника. Разгон и торможение задаются отдельно: тяжёлый грузовик может разгоняться 2 с, а останавливаться за 0,5 с. Для света Плавность включает и гасит его постепенно.

## Защёлка

Превращает кнопку в переключатель: нажали один раз — вкл, ещё раз — выкл. *Кнопка* → *Защёлка* → *Свет*.

## Советы

- Порядок важен: *Мёртвая зона → Ограничение → Плавность* — хорошая цепочка для езды.
- Обработку, которая не подходит к сигналу, поставить нельзя: например, Защёлке нужен вход вкл/выкл.
- Во время работы следите за текущими значениями — так видно, что делает каждый блок.
