# Примеры

Короткие программы, с которых можно начать. Названия блоков — как в [справочнике блоков](/docs/Application/BlockBuilder/Blocks/BlocksIntroducing#block-reference). Отступ означает «внутри» C-блока.

## Езда джойстиком

Панель: **JOY1**. Мотор на порту A.

```text
Когда программа запущена
Всегда
    Установить скорость мотора  (Хаб 1, порт A)  ←  значение джойстика JOY1, ось y
```

## Руление серво

Рулевой мотор (угловой) на порту B. Откалибруйте один раз, затем следуйте за джойстиком.

```text
Когда программа запущена
Калибровать рулевую рейку  (Хаб 1, порт B)
Всегда
    Перейти к относительной позиции  (Хаб 1, порт B)  ←  значение джойстика JOY1, ось x × 0.9
```

## Свет на переключателе

```text
Когда переключатель SWCH1 включён
    Переключить свет на 100 %  (Хаб 1, порт C)
Когда переключатель SWCH1 выключен
    Выключить свет  (Хаб 1, порт C)
```

## Предупреждение о батарее

Монитор **MNTR1**; кнопка становится красной, когда батарея садится.

```text
Когда программа запущена
Всегда
    Показать  (Уровень батареи хаба (Хаб 1))  на мониторе MNTR1
    Если  Уровень батареи хаба (Хаб 1) < 20
        Установить цвет контроллера BTN1: красный
    Ждать 5 секунд
```

## Остановка перед препятствием

Датчик расстояния Technic на порту D, ходовой мотор на порту A.

```text
Когда программа запущена
Всегда
    Если  Technic датчик расстояния (Хаб 1, порт D) < 10
        Остановить мотор  (Хаб 1, порт A)
        Установить цвет LED  (Хаб 1)  красный
    Иначе
        Установить скорость мотора  (Хаб 1, порт A)  ←  значение слайдера SLDR1
        Установить цвет LED  (Хаб 1)  зелёный
```

## Коробка передач на шаговом переключателе

Шаговый переключатель **STPR1** с 4 ступенями ограничивает максимальную скорость.

```text
Когда программа запущена
Всегда
    Установить переменную (предел скорости) в  (шаговый переключатель STPR1 × 25)
    Установить скорость мотора  (Хаб 1, порт A)  ←  значение педалей PDL1 × предел скорости / 100
```

`предел скорости` — это переменная (**Переменные → Создать переменную**).

## Проверка при запуске

Газ заблокирован, пока не подключатся оба хаба.

```text
Когда программа запущена
Установить интерактивность контроллера JOY1  выключить
Ждать до  (Подключен (Хаб 1))  и  (Подключен (Хаб 2))
Показать "Готово" на мониторе MNTR1
Установить интерактивность контроллера JOY1  включить
```

## Геймпад

```text
Когда программа запущена
Всегда
    Установить скорость мотора  (Хаб 1, порт A)  ←  стик геймпада левый y
    Перейти к относительной позиции  (Хаб 1, порт B)  ←  стик геймпада правый x × 0.9
```

Сначала включите **Включить блоки геймпада** на [странице «Геймпад»](/docs/Application/Dashboard/Gamepad).
