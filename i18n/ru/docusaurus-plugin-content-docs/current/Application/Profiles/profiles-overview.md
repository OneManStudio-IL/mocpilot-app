# Профили

**Профиль** — это всё, что MOCPilot знает об одной модели: её хабы, панель управления и программа. На каждую модель — свой профиль.

<Screenshot name="profiles-desktop" alt="Список «Мои профили»" width={900} />

## Откуда берутся профили

- **Ваши собственные профили**, созданные через **Новый профиль**. См. [Создание профиля](/docs/Application/Profiles/CreateProfile).
- **Профили из каталога**: официальные профили для наборов LEGO® от команды MOCPilot и профили сообщества от других строителей. При установке в ваш список добавляется ваша собственная копия. См. [Каталог и публикация](/docs/Application/Profiles/Catalog).
- **Импортированные профили**: файлы `.dat`, которыми с вами поделились. См. [Управление профилями](/docs/Application/Profiles/ManageProfiles#import-a-profile).

Все они находятся в одном списке.

## Список профилей

На телефоне страница называется **Профили**, на планшете и компьютере — **Мои профили**.

- **Поиск** находит профили по названию, хэштегу, автору, хабу, номеру набора или году.
- **Сортировка и фильтр** сортирует по вариантам **Новейшие наборы**, **Старейшие наборы**, **Название (А–Я)**, **Название (Я–А)**, **Автор (А–Я)**, **Автор (Я–А)** или **Используемые хабы**. **Только мои профили** скрывает профили, установленные из каталога.
- **Фильтр по хэштегам** показывает только профили с выбранными хэштегами.
- **Сетка** / **Столбец** переключает вид карточек (планшет и компьютер).
- **Избранные** профили всегда показываются первыми.

На карточке видны изображение и название профиля, а если известны — номер набора, год выпуска и количество деталей. **Доступно обновление** означает, что можно установить новую версию профиля из каталога.

## Действия с профилем

| Действие | Телефон и планшет | Компьютер |
|---|---|---|
| Открыть (запустить) | нажмите на карточку | двойной щелчок по карточке или **Запустить** |
| Изменить название, изображение, хэштеги, описание | **Редактировать** на карточке | **Изменить…** |
| Добавить в избранное | в **Редактировать профиль** | **В избранное** |
| Поделиться файлом | **Поделиться** | **Поделиться…** |
| Обновить из каталога | **Обновить** | **Обновить** |
| Опубликовать в каталоге | в **Редактировать профиль** | в **Редактировать профиль** или **Опубликовать профиль** |
| Удалить | **Проведите, чтобы удалить профиль** в **Редактировать профиль** | **Удалить профиль** в **Редактировать профиль** |

## Два вида программ

Каждый профиль использует один из двух редакторов программ, который выбирается при создании:

- **Быстрые связи**: строки, которые связывают элементы управления с моторами и светом, без кода. См. [Быстрые связи](/docs/Application/Links/LinksIntroducing).
- **Логические блоки**: блочная программа с событиями, циклами, условиями и переменными. См. [Логические блоки](/docs/Application/BlockBuilder/Blocks/BlocksIntroducing).

:::info
Профиль, созданный в более новой версии MOCPilot, может не открыться в старой («Профиль несовместим»). Обновите приложение на этом устройстве.
:::
