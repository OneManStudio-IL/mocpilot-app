# Создание профиля

1. Откройте список профилей.
   - Телефон: нажмите **+** → **Новый профиль**.
   - Планшет: **Новый профиль** в шапке.
   - Компьютер: **Файл → Новый профиль** (⌘N / Ctrl+N).
2. Выберите **тип программы** (см. ниже).
3. Заполните данные профиля.
4. Нажмите **Создайте и начните строить** (телефон) или **Создать** (планшет и компьютер). Профиль откроется в редакторе.

## Выберите тип программы {#choose-the-program-type}

Тип программы определяет, какой редактор использует профиль. **Изменить его потом нельзя.** Если хотите попробовать другой редактор, создайте второй профиль.

| | Быстрые связи | Логические блоки |
|---|---|---|
| Как строится | Строки: вход → обработка → операция → хаб | Блоки, собранные в скрипты |
| Время на освоение | Минуты | Больше; и возможностей больше |
| Лучше всего для | Машин, грузовиков, поездов, кранов: «этот элемент двигает тот мотор» | Роботов, автоматических последовательностей, логики на датчиках, игр |
| Логика (условия, циклы, переменные) | Нет (только пороги и защёлки) | Да |
| Датчики | Датчики хаба как входы; значения на индикаторы | Все датчики хабов и телефона, любые вычисления |
| Плавный старт, ограничения, мёртвая зона | Готовые блоки | Собираются из блоков |
| Рулевое серво с калибровкой | Готовый блок | Блоки |
| Геймпад | Да | Да |
| Несколько хабов | Да | Да |

**Сомневаетесь?** Начните с Быстрых связей. Если позже понадобится логика, создайте для модели профиль с Логическими блоками.

Если попытаться создать профиль, не выбрав тип, плитки подсветятся. На каждой плитке есть ссылка **Документация ↗** на эту документацию.

## Данные профиля

- **Изображение**: нажмите (на сенсорных экранах — долгое нажатие) на область изображения, чтобы выбрать картинку. Сдвиньте изображение по вертикали, чтобы выбрать видимую часть. **Обновить изображение** и **Удалить** позволяют поменять его позже.
- **Название**: обязательное и уникальное; сообщение «Профиль с названием … уже существует» означает, что профиль с таким названием у вас уже есть.
- **Уровень блоков** (только Логические блоки): **Новичок**, **Продвинутый** или **Гуру**. Определяет, какие блоки показываются в палитре этого профиля. Его можно изменить позже в Настройках редактора. См. [Работа в редакторе](/docs/Application/BlockBuilder/Editor#block-levels).
- **Хэштеги**: описывают профиль и помогают в поиске. Хэштеги выбираются из общего списка; он загружается, когда вы в сети.
- **Избранный**: избранные профили показываются в списке первыми.

Все данные, кроме типа программы, можно изменить позже в **Редактировать профиль**.
