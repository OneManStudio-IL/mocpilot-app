# Создание элементов управления из темы

Каждый добавляемый элемент начинается с темы. Перед добавлением его можно настроить, а настроенный элемент — сохранить как собственный дизайн.

## Настройка перед добавлением

1. Откройте **Добавить контроллер** (**+** на панели).
2. Выберите элемент на вкладке **Элементы управления** или **Специальные**.
3. В разделе **Настроить** используйте вкладки **Стиль** и **Настройки**: размер (панель показывает «Ш x В точек»), акцентный цвет, иконку, параметры темы, поведение.
4. Нажмите **Добавить на панель**.

## Сохранение дизайна

Нашли удачное сочетание (скажем, красную кнопку Racing с иконкой гудка)? Сохраните его:

1. Выберите ровно один настроенный элемент из вашей темы.
2. Нажмите **Сохранить дизайн**.
3. Дизайн появится на вкладке **Сохранено**. Добавляйте его на любую панель любого профиля в одно касание.

**Удалить** удаляет сохранённый дизайн.

## Копирование элементов на панели

- **Дублировать** копирует элемент со всеми его свойствами.
- **Дублировать (Только тип)** добавляет элемент того же типа со свойствами по умолчанию.
- **Сменить тему** переключает элемент на другую вашу тему, не меняя его места и связей с программой.

## Удобная панель

- Размещайте элементы для езды под большими пальцами: джойстик или педали с одной стороны, руль — с другой.
- Используйте размер **L** для самых нужных элементов и **S** — для редких.
- Один акцентный цвет на одну функцию: зелёный — движение, жёлтый — свет, красный — стоп.
- Когда раскладка готова, заблокируйте элементы (**Заблокировать все**).
- Добавьте монитор батареи, чтобы знать, когда пора заряжать.

:::info Своя графика
Рисовать полностью новые элементы или темы в приложении нельзя. Темы делает команда MOCPilot; если у вас есть идея темы, напишите нам через **Помощь → Задать вопрос**.
:::
