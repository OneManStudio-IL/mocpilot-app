# Свойства элементов управления

В режиме редактирования нажмите (кликните) на элемент, чтобы открыть его свойства.

- **Телефон и планшет**: панель поверх экрана управления; нажмите за её пределами, чтобы закрыть.
- **Компьютер**: боковая панель; пока она открыта, можно продолжать работать с панелью управления.

<Screenshot name="controller-properties" alt="Панель свойств элемента с вкладками «Стиль» и «Настройки»" width={900} />

В заголовке — имя элемента (например, **JOY1**), кнопка корзины, меню дублирования и **OK**.

## Вкладка «Стиль»

- **Размер**: S, M или L. См. [размеры](/docs/Application/Dashboard/ArrangingControls#sizes).
- **Акцентный цвет**: основной цвет элемента.
- **Иконка**: картинка на элементе (кнопки, переключатели, мониторы), на выбор более 260 иконок.
- Параметры темы, зависят от темы: например, **Colored carbon**, **Colored bezels** и **Show race lines** в Racing, **Indicator segments count** в Building machinery, **Display values** в Aura.
- **Сменить тему**: переключить элемент на другую вашу тему с таким же типом элемента.

## Вкладка «Настройки»

Общие настройки:

- **Заблокировать контроллер**: заблокированный элемент нельзя переместить или удалить.
- **Интерактивность**: неинтерактивный элемент не регистрирует нажатия.

Настройки отдельных типов:

| Элемент | Настройки |
|---|---|
| Джойстик | **Тип осей**: Обе оси (X, Y), Только по горизонтали (X), Только по вертикали (Y) |
| Ползунок, Вер. ползунок | **Возврат к нулю**, **Отрицательные значения**, **Шаговое значение** |
| Шаговый переключатель, Вер. шаговый переключатель | **Количество шагов** (1–100), **Отрицательные значения**, **Включить сброс** |
| Монитор | **Макет текста**, **Переполнение текста**, **Максимум строк**, **Направление прокрутки**, **Скорость прокрутки**, **Показывать полосу прокрутки**, **Интерактивная прокрутка**, **Выравнивание текста**, **Масштаб текста** |
| Наклонный монитор | **Инвертировать наклон**, **Инвертировать вращение** |
| Руль | **Угол поворота руля**, **Звуковые эффекты** |
| Педали | **Инерция двигателя**, **Скорость заднего хода**, **Звуковые эффекты** |

У числовых настроек есть кнопка **Сбросить**, которая возвращает значение по умолчанию.

## Изменение свойств из программы

В Логических блоках блоки могут менять элемент во время работы программы: задавать его цвет, переключать интерактивность, выводить значения на мониторы. См. [Блоки контроллеров панели](/docs/Application/BlockBuilder/Blocks/DashboardControllers).
