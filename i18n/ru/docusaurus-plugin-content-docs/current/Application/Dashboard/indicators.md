# Индикаторы и мониторы

Мониторы показывают информацию на панели, пока вы управляете моделью: заряд батареи, скорость, наклон, расстояние до препятствия, текущую передачу или режим.

| Монитор | Что показывает | Тема |
|---|---|---|
| **Монитор** | текст или число | все темы |
| **Уровень заряда батареи** | шкалу уровня | платные темы |
| **Спидометр** | шкалу скорости | платные темы |
| **Наклонный монитор** | тангаж и крен модели | платные темы |

Мониторы только показывают — управлять ими нельзя. Что на них выводить, решает программа.

## В Быстрых связях

Используйте выход **Индикатор**. Строка заканчивается индикатором вместо хаба:

- *Хаб* (Батарея) → *Индикатор* (Уровень заряда батареи): заряд батареи хаба на шкале.
- *Хаб* (Скорость мотора, порт A) → *Индикатор* (Спидометр).
- *Хаб* (Наклон: тангаж) → *Индикатор* (Наклонный монитор, Наклон X) и вторая строка для крена (Наклон: крен) → Наклон Y.
- *Хаб* (Напряжение батареи) → *Индикатор* (Монитор): показывает значение с единицей измерения, например «7.85 V».

Индикатор показывает значение как есть, поэтому операций в такой строке нет. См. [Операции и выходы](/docs/Application/Links/Operations#indicator).

## В Логических блоках

Используйте блоки контроллеров панели:

- *Установить значение монитора* и *Показать на мониторе* — для Монитора, Уровня заряда батареи и Спидометра;
- *Установить значение монитора наклона* — для Наклонного монитора.

Вывести можно всё, что получается посчитать: показания датчика, переменную, текст вроде «Передача 2». См. [Контроллеры панели](/docs/Application/BlockBuilder/Blocks/DashboardControllers).

## Советы

- Разместите монитор батареи в углу, где его не закрывают пальцы.
- Для длинных сообщений используйте многострочный Монитор с переполнением **Бегущая строка** или **Прокрутка**.
- Программа может менять цвет любого элемента — например, кнопка становится красной, когда батарея садится.
