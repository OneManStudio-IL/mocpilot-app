# Create controls from a theme

Every control you add starts from a theme. Before adding it, you can configure it, and you can save your configured control as your own design.

## Configure before adding

1. Open **Add Controller** (**+** on the dashboard).
2. Select a control in **Controls** or **Special**.
3. In **Configure**, use the **Style** and **Settings** tabs: size (the panel shows "W x H dots"), accent colour, icon, theme options, behaviour.
4. Tap **Add to dashboard**.

## Save a design

When you find a combination you like (say, a red Racing button with a horn icon), keep it:

1. Select exactly one configured control of a theme you own.
2. Tap **Save design**.
3. The design appears in the **Saved** tab. Add it to any dashboard of any profile in one tap.

**Delete** removes a saved design.

## Copy controls on the dashboard

- **Duplicate** copies a control with all its properties.
- **Duplicate (Type Only)** adds the same control type with default properties.
- **Change theme** switches a control to another owned theme without losing its place or program connections.

## A good dashboard

- Put driving controls where your thumbs are: a joystick or pedals on one side, steering on the other.
- Use **L** size for the controls you use most and **S** for rare ones.
- Use one accent colour per function: green for driving, yellow for lights, red for stop.
- Lock the controls when the layout is ready (**Lock all**).
- Add a battery monitor so you know when to recharge.

:::info Your own graphics
Drawing completely new controls or themes is not possible in the app. Themes are made by the MOCPilot team; if you have an idea for a theme, tell us through **Help → Ask a question**.
:::
