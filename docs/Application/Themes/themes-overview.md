# What is a theme

A **theme** is a visual style for dashboard controls. All themes have the same control types (joystick, sliders, buttons, switches, step switches, monitors) and they all work the same way; only the look is different.

You can mix themes on one dashboard: each control has its own theme.

## Available themes

| Theme | Price | Controls |
|---|---|---|
| **Basic** | free, built in | Joystick, Directional Pad, Slider, Ver. slider, Button, Switch, Step switch, Ver. step switch, Monitor |
| **Racing** | paid | all Basic controls plus Battery level, Speedometer, Tilt monitor |
| **Building machinery** | paid | the same set in its own style |
| **Hi-Fi Audio** | paid | the same set in its own style |
| **Aura** | paid | the same set in its own style |

New themes are added from time to time; they appear in the palette automatically.

**Special controls** are separate products: the **Steering wheel** and **Pedals**, each in Supercar, Heavy truck and Off-road vehicle styles.

All paid themes and special controls are included in [MocPilot Pro](/docs/Application/Account/Pro).

## Theme options

Some themes have their own options in the control's **Style** tab, for example:

- Racing: **Colored carbon**, **Colored bezels**, **Show race lines**;
- Building machinery: **Indicator segments count**;
- Aura: **Display values**.

## Change the theme of a control

Long-press (right-click) a control → **Change theme**, or use **Change theme** in its properties. You can switch to any theme you own that has the same control type. Position, size and program connections stay.
