# Get, buy and update themes

There is no separate store screen: you browse and buy themes right where you use them, in the **Add Controller** palette of the dashboard.

## Try a theme

1. Open the dashboard and tap **+** (**Add Controller**).
2. In **Controls**, scroll to the theme. Every control is shown as a live preview. **Special** has steering wheels and pedals.
3. Select a control and look at it in **Configure**: colours, sizes, options.

In the [web editor demo](/docs/Introducing/WebEditor) on mocpilot.com you can even place paid controls and try them.

## Buy

For a theme you don't own the palette shows:

- **Purchase &lt;price&gt;**: buy this theme (or this special control) once; it is yours forever;
- **All with MocPilot Pro**: get every theme and special control with the subscription. See [MocPilot Pro](/docs/Application/Account/Pro).

Purchases go through the App Store, Google Play or Microsoft Store and belong to your MOCPilot account, so you need to be signed in. They work on all your devices and in the web editor.

## Install and update

You don't install themes by hand. When you are signed in, MOCPilot downloads the themes you own and keeps them up to date automatically. The free Basic theme is built in.

If a theme is missing:

- check the internet connection and that you are signed in to the right account;
- go to **Account → Purchases** and tap **Restore** (Restore Purchases);
- restart the app.

## Profiles with themes you don't own

- A profile installed from the [catalog](/docs/Application/Profiles/Catalog) runs with all its themes as long as you don't change it.
- When you edit a profile with themes you don't own, those controls switch to the Basic theme; special controls (steering wheel, pedals) are locked until purchased.

## Alternative stores

In **Account → Purchases → Purchases settings** you can **Use alternative store** and **Open in the system browser** for the payment page. These are for regions where the usual stores are not available.
